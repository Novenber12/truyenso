# Product Images for Truyện Số

This directory contains cover images for novels displayed on the website.

## Recommended Image Specifications:
- **Format**: JPG, PNG, or WebP
- **Dimensions**: 300x400px (3:4 aspect ratio)
- **File size**: Under 200KB
- **Quality**: High quality, clear images

## Naming Convention:
- `novel1.jpg` - Cover for "Tu Tiên Đại Đế"
- `novel2.jpg` - Cover for "Ma Đế Tái Sinh"
- `novel3.jpg` - Cover for "Võ Thần Quyết"
- `novel4.jpg` - Cover for "Thần Cấp Hệ Thống"

## Placeholder Images:
If you don't have actual cover images, the website will automatically use placeholder images from:
`https://via.placeholder.com/300x400/6366f1/ffffff?text=Truyện+Số`

## Adding New Images:
1. Save your image with the appropriate name (e.g., `novel5.jpg`)
2. Update the corresponding novel data in the Home component
3. Ensure the image path matches the data structure

## Image Sources:
- Use royalty-free images or images you have rights to use
- Consider using AI-generated images for placeholder content
- Ensure images are appropriate for the novel genre and content
